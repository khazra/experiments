# Sector-selection framework

The first run cannot establish which sector was best: opportunities, probes, effort, and conversions were not normalized. A future authorized study should make sector selection measurable before doing work.

## Required record per candidate sector

| Field | Requirement |
| --- | --- |
| Sector ID | Stable identifier independent of a platform or one listing |
| Eligible buyer type | Defined without personal data |
| Demand observation | Dated public signal or explicit invitation |
| AI eligibility | Human-verified terms or explicit written permission |
| Identity/KYC | Required attestations and who lawfully supplies them |
| Settlement path | Entitlement → transfer → available → spendable |
| Window fit | Worst documented review/hold time versus deadline |
| Entry cost | Cash, account, reputation, software, and human-time inputs |
| Acceptance criteria | Objective and subjective criteria separated |
| Probe | Smallest lawful test, including a capped sample if it resolves an explicit uncertainty |
| Stop rule | Evidence that closes the tested route or cohort, with the scope stated |

## Comparison rule

Do not rank sectors until each has the same minimum fields. Unknown is not prohibited, but it is not qualified. Compare only unique, deduplicated opportunities with effort and outcome captured under the same definitions. “No current item in the register” is not evidence that the sector has no worthwhile unexplored route.

## Selection gate

A sector may receive production effort only after:

1. at least one reachable buyer-side demand signal;
2. lawful AI/account eligibility;
3. a settlement path that fits the window;
4. stated acceptance criteria;
5. a bounded probe and stop rule;
6. an explicit future authority policy for delegated actions and approval boundaries.

If no sector passes, the valid result is “no qualified sector under the registered constraints.” Do not manufacture work to avoid that result.

## Bounded qualitative sector screen

Global sector optimality is not measurable here, but concrete gates can still be compared. Screen a small, diverse set rather than defaulting to SaaS: scoped professional services, editorial/creative work, paid open-source contributions, small digital products and local operations. Record evidence quality and disqualifiers; do not infer conversion rates from these categories.

Give each candidate a fixed research budget and one low-cost demand test. Prefer shorter verifiable acceptance and collection paths for a short cash objective, while tracking identity, reputation, audience and human help as explicit endowments. Move to deeper research or a buyer relationship only when the first test justifies the additional effort. Review the unused alternatives when a route closes; the absence of a qualified register entry is not market exhaustion.
