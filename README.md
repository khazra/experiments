# Earn50 run 01 postmortem

At the September 22, 2026 pause, the experiment's ledger recorded **USD 0 accepted-and-paid earnings** after **96h15m09s of a planned 120 hours**. The final 23h44m51s is unobserved. This is a cutoff ledger result, not a fresh audit of every wallet or a completed five-day verdict. [E-FUNNEL-001] [E-SCOPE-004] [E-SCOPE-008]
